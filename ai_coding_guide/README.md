# The AI Coding Guide

A plain-language field guide to how AI-assisted software development actually works in 2025–2026 — the models, the tools, the workflows, the jargon, and the responsibility that comes with all of it.

This is written for someone who can already code but is new to the *AI-native* way of building things: the agentic loops, the context engineering, the MCP servers, the skills, the rules files, and the rest of the vocabulary that has exploded since late 2024. By the end you should be able to hold a conversation about AI coding without faking it, and know where to go next.

---

## How to read this

Start at Chapter 1 and go in order if everything is new. If you already know the basics, jump to whichever chapter answers your question — each is written to stand on its own. The glossary (Chapter 12) is the one to bookmark: it defines every term the rest of the guide throws around, including the newest ones people are using in 2026.

## A note on dates and drift

AI coding moves fast. The core mental model in Chapters 2–4 is durable. The tool landscape in Chapter 10 will be partly out of date by the time you read this — treat it as a snapshot, and verify against each project's current docs. The glossary is the most stable part, because vocabulary tends to outlive any single product.
