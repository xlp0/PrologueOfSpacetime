## New Teaching Material

### [NEW] [The AI Coding Workflow Handbook](../teaching/ai_coding_handbook.md)
* **Description**: A long-form reference handbook (~810 lines, 13 sections) for intermediate developers transitioning from casual ChatGPT/Copilot use to professional, verifiable, multi-tool agentic workflows.
* **Audience**: Working developers who have used AI chat tools but are new to MCP, skills, and agentic workflows.
* **Tone**: Plain professional — no project-internal vocabulary (CLM, Trivium, Quadrivium) is assumed.
* **Coverage**:
  - **Mental model** of LLMs, context windows, and the agentic loop — the foundation that prevents common mistakes.
  - **Prompting discipline**: the four-part prompt (Goal, Context, Constraints, Done), the Spec-Implement-Verify loop, and anti-patterns.
  - **MCP (Model Context Protocol)**: what it is, why it matters, anatomy of servers/clients/tools/resources, how to install and author MCP servers, and how it relates to function calling.
  - **Agent skills**: what a skill is, how skills differ from MCP tools, the `SKILL.md` format, when to author a skill, and skill discovery/sharing.
  - **Agentic workflow patterns**: when to use agents vs. direct chat, the direct-edit pattern, plan-then-execute, subagent delegation, explore-then-edit, verify-and-loop, context management, and when to intervene.
  - **Concrete tooling walkthrough**: opencode, Claude Code, Cursor, Aider, Claude Desktop — with a side-by-side comparison and a concrete end-to-end session example.
  - **Code of conduct and professional practice**: the "you are responsible" rule, verification discipline, security (prompt injection, least privilege, secrets), IP/licensing, attribution, when NOT to use AI, team norms, cost awareness, and honesty.
  - **Reference workflow**: a one-page summary of the professional agentic workflow (before/during/after), tool selection table, and when to stop the agent.
  - **Glossary** of 20+ terms and a curated **further reading** list.
* **Location**: `docs/teaching/ai_coding_handbook.md` (new directory created for teaching material).
