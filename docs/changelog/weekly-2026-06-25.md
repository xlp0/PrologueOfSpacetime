## New Teaching Material

### [RESTRUCTURE] AI Coding Handbook split into 13 chapters
The single-file `docs/teaching/ai_coding_handbook.md` has been split into a 13-chapter handbook under `docs/teaching/handbook/`, with a README index tying them together. Language was simplified so a 14-year-old can follow along — each chapter explains one idea and what it is **for**, not how to use it.

The chapters:
- `01_what_is_ai_coding.md` — What AI coding tools are, why they matter, what changed 2023-2026.
- `02_how_ai_tools_work.md` — The model (brain), the harness (body), the agentic loop, why tools matter more than prompting.
- `03_the_stack.md` — The four layers (model, harness, MCP client, MCP server) and what each is for.
- `04_tokens_and_context.md` — What tokens are, the context window, why "more is not better."
- `05_prompting_styles.md` — Zero-shot, few-shot, caveman, chain-of-thought, role, step-back, self-consistency, tree of thoughts, instruction vs. conversation, the four-part prompt, anti-patterns.
- `06_context_engineering.md` — Curating what the AI sees; the five levers (file selection, tool selection, subagents, system prompt, session management).
- `07_mcp.md` — What MCP is, the four concepts (server, client, tools, resources), 12 example servers (filesystem, GitHub, Postgres, PalmierPro, Slack, Puppeteer, Fetch, Memory, SQLite, Brave Search, Linear/Jira, Sentry).
- `08_agent_skills.md` — What a skill is, skills vs. tools, the SKILL.md format, 6 example skills (codebase exploration, video analysis, parallel execution, skill discovery, multi-agent orchestration, code review), why skills reduce tokens (4 mechanisms).
- `09_agentic_workflows.md` — When to use agents (multi-step, verifiable, bounded), 5 patterns (direct edit, plan-then-execute, subagent delegation, explore-then-edit, verify-and-loop), context management, when to intervene.
- `10_the_tools_people_use.md` — opencode, Claude Code, Cursor, Aider, Claude Desktop — what each is good at, how to choose.
- `11_code_of_conduct.md` — "You are responsible," verification discipline, security (prompt injection, least privilege, secrets), IP/licensing, attribution, when NOT to use AI, team norms, cost awareness, honesty.
- `12_words_youll_hear.md` — Plain-language glossary of ~35 terms (harness, agent, subagent, skill, MCP, tool, resource, prompt, system prompt, context window, context engineering, token, embedding, RAG, vector database, fine-tuning, sampling, temperature, chain-of-thought, few-shot, zero-shot, hallucination, prompt injection, tool call, JSON Schema, stdio, Skills CLI, lock file, AGENTS.md, knowledge graph, eval, guardrails).
- `13_where_to_learn_more.md` — Specifications, reference servers, essays, skills to study, code of conduct references, habits for keeping up.

The old single-file handbook (`docs/teaching/ai_coding_handbook.md`) has been removed. The new structure lives at `docs/teaching/handbook/` with `README.md` as the index.
