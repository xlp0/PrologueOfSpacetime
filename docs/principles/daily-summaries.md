# Daily Summaries — Narrative Practice

## Purpose
A daily log for practicing the narrative discipline Prof. Ben Koo demands: **lead with effect, zoom out to bigger picture.** Not "I did X, Y, Z" but "this happened → it means this → here's the national picture." Reps every day until it becomes default speech. The audience is Pak Luhut (every few weeks) and Pak Prabowo — both decide whether this scales. See [[prof-ben-koo-speeches]] for the source instruction and [[ben-koo-capability-building-method]] for the underlying method.

## Entry template
For each entry, write three short blocks:

1. **Act** — what concretely happened today (1–2 sentences, factual).
2. **Effect** — what it produced or unlocked (1–2 sentences, the "so what").
3. **Bigger picture** — why it matters for Indonesia / sovereign capability / builders mindset (1–2 sentences, zoom out).

Optional: **Voice note** — link or transcript snippet if a voice note was recorded that day.
Optional: **Open question / next step** — what to bring to the next Luhut/Prabowo conversation.
