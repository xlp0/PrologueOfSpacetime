# AI Evaluation as Bridge Positioning

## Insight
The core positioning move across all of Ilham's job applications in 2026: **reframe AI Trainer / QA / Calibrator past as AI-evaluation / AI-ops positioning**, rather than pretending to be a senior ML engineer. The resume was underselling in 3 ways — (1) it sounded too generic QA/data-analytics ("quality assurance, KPI reporting, process improvement" reads like ops at a BPO); (2) it didn't clearly frame OpenAI-side work as LLM post-training; (3) the strongest technical angle was buried (tool-use evaluation, prompt-response evaluation, multilingual model evaluation, post-training data quality, calibration, structured feedback loops).

The reframe: **"I worked in the post-training / evaluation layer of LLM systems"** — that is the valuable angle. Resume bullets should say LLM evaluation, post-training review workflows, reasoning quality / factual accuracy / instruction-following, human-feedback tasks, RLHF-related projects, calibration drift / disagreement patterns, model-evaluation pipelines. Not "improved training consistency / quality analytics / evaluated annotation datasets" — that's generic QA at an AI outsourcing company.

**Headline options:** `LLM Post-Training, Evaluation & Quality Analytics Specialist` (safest / strongest); `AI Post-Training, Model Evaluation & Quality Operations Specialist` (for AI QA / eval / ops roles); `AI Quality Analytics & LLM Evaluation Specialist` (for data/analytics roles too). "AI Operations" alone is vague.

**Strong-but-safe claims:** multilingual LLM evaluation, post-training workflows, reasoning quality / factual accuracy / instruction-following, RLHF-related projects, human-feedback tasks, model-evaluation pipelines. **Stronger / use only if defensible in interview:** tool-use evaluation, memory/browsing workflows, JSON schema review, SFT dataset curation, preference ranking between model outputs. Don't bluff architecture you didn't directly touch — that's how you get caught in 2 follow-up questions and die on the hill.

What does NOT belong: pretending to have built model architecture, trained GPT from scratch, or done production ML engineering. The clean framing: *"I worked on the data/quality side rather than model architecture itself. My role was closer to improving training and evaluation data pipelines: reviewing outputs, checking instruction-following quality, spotting failure cases, and helping structure data that could be used for model improvement. So I wasn't training foundation models from scratch, but I was part of the feedback loop that improves them."* That's clean. No cosplay as a research scientist.

## Context
Crystallized 2026-06-24 (Work at OpenAI Explained) and 2026-06-19 (Standing Out as a Candidate). The reframe was repeated across Awaz, Ilant, Lens, Jobrooms, Picea, and the June-17 Wellfound batch.
