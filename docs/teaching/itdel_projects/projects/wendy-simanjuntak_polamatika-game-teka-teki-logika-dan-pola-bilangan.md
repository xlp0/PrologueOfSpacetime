## 1. Deskripsi Proyek (Indonesian)
Nama Game: 
PolaMatika (Game Teka-Teki Logika dan Pola Bilangan)

Tujuan Projek:
Tujuan dari projek PolaMatika adalah melatih kemampuan penalaran logis, ketajaman analisis kuantitatif, dan kecepatan berpikir komputasional pengguna melalui pemecahan teka-teki pola barisan angka dan matriks matematika.

Fungsi Utama:
a. Menyediakan tiga mode permainan utama, yaitu Mode Petualangan tiga puluh level terstruktur, Mode Serangan Waktu enam puluh detik, dan Mode Tanpa Batas berbasis algoritma acak.
b. Menyajikan beragam variasi pola matematika mulai dari aritmatika bertingkat, barisan geometri, deret Fibonacci, hingga matriks logika angka ukuran tiga kali tiga.
c. Menyediakan dua metode penginputan jawaban, yaitu mode tombol pilihan ganda dan mode papan tombol angka virtual untuk pengetikan mandiri.
d. Menampilkan visualisasi petunjuk dan pembahasan rumus matematika lengkap langkah demi langkah untuk setiap soal yang diujikan.
e. Mencatat data statistik performa pengguna yang meliputi tingkat akurasi persentase, rekor kombo tertinggi, perolehan skor, dan penghargaan lencana prestasi. 

### Fitur & Fungsi Utama
a. Menyediakan tiga mode permainan utama, yaitu Mode Petualangan tiga puluh level terstruktur, Mode Serangan Waktu enam puluh detik, dan Mode Tanpa Batas berbasis algoritma acak.
b. Menyajikan beragam variasi pola matematika mulai dari aritmatika bertingkat, barisan geometri, deret Fibonacci, hingga matriks logika angka ukuran tiga kali tiga.
c. Menyediakan dua metode penginputan jawaban, yaitu mode tombol pilihan ganda dan mode papan tombol angka virtual untuk pengetikan mandiri.
d. Menampilkan visualisasi petunjuk dan pembahasan rumus matematika lengkap langkah demi langkah untuk setiap soal yang diujikan.
e. Mencatat data statistik performa pengguna yang meliputi tingkat akurasi persentase, rekor kombo tertinggi, perolehan skor, dan penghargaan lencana prestasi.

PolaMatika adalah game teka-teki logika matematika interaktif yang difokuskan pada pengasahan daya analisis deret bilangan, pola barisan, dan matriks kecerdasan. Pemain ditantang untuk menemukan angka berikutnya pada berbagai variasi pola, seperti deret aritmatika bertingkat, barisan geometri, bilangan Fibonacci, pola kuadrat, hingga matriks logika berukuran tiga kali tiga. Dilengkapi dengan sistem bantuan petunjuk bertahap, visualisasi pemecahan masalah, modul pembahasan rumus matematis komprehensif, serta akumulasi skor dan kombo beruntun, PolaMatika dirancang sebagai sarana latihan berpikir kritis yang efektif untuk persiapan tes potensi akademik, logika komputasi, dan penalaran kuantitatif secara mandiri.

## 2. Project Description (English Translation)
An interactive math puzzle game focusing on numerical pattern recognition, arithmetic series, geometric progressions, Fibonacci sequences, quadratic relations, and 3x3 logic matrices with progressive hints, step-by-step solution derivations, and combo streaks.
