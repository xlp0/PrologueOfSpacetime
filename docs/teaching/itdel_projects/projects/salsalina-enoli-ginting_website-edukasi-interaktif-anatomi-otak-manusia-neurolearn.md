# Website Edukasi Interaktif Anatomi Otak Manusia (NeuroLearn)

## 1. Deskripsi Proyek (Indonesian)
NeuroLearn* adalah aplikasi web pembelajaran berbasis visual yang dirancang untuk mempermudah pemahaman struktur anatomi otak manusia. Pengguna dapat mengeksplorasi model anatomi secara langsung; setiap bagian otak yang diklik akan menyorot area tersebut sekaligus menampilkan penjelasan mendalam mengenai nama ilmiah, lokasi, serta fungsi fisiologisnya secara dinamis.

## 2. Project Description (English Translation)
A visual medical education web platform that allows users to explore a dynamic 3D anatomical model of the human brain. Clicking any brain lobe highlights the region and surfaces physiological functions, clinical pathology, and self-assessment quizzes.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Menyediakan media belajar biologi dan neuroanatomi yang interaktif, visual, dan mudah diakses.
  2. Meningkatkan retensi pemahaman pengguna melalui interaksi langsung dibanding metode membaca teks statis.
  3. Menguji pemahaman pengguna secara mandiri melalui kuis identifikasi bagian otak secara *real-time*.

---

## 4. Project Objectives (English Translation)
1. Make neuroanatomy accessible and intuitive through interactive 3D exploration.
2. Increase knowledge retention compared to static textbook diagrams.
3. Provide self-paced quiz modules to test anatomical identification in real time.
