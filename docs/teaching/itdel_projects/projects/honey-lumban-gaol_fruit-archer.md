## 1. Deskripsi Proyek (Indonesian)
Fruit Archer adalah game sederhana di mana pemain berperan sebagai pemanah yang harus menembakkan panah ke buah-buahan yang bergerak. Pemain mendapatkan poin setiap kali berhasil mengenai buah. Semakin lama permainan berlangsung, buah akan bergerak semakin cepat sehingga permainan menjadi lebih menantang.

## 2. Project Description (English Translation)
An arcade archery challenge where players draw and release arrows to pop dynamic moving fruits, with increasing projectile velocities and shifting wind patterns testing player aim.

---

## 3. Tujuan Proyek (Indonesian Objectives)
Tujuan game ini adalah melatih ketepatan dan kecepatan pemain dalam membidik serta menembakkan panah ke buah yang bergerak. Selain mendapatkan skor sebanyak-banyaknya, game ini juga bertujuan untuk melatih konsentrasi, fokus, ketelitian, dan kemampuan mengambil keputusan dengan cepat karena kecepatan buah akan terus meningkat selama permainan.

## 4. Project Objectives (English Translation)
1. Train visual tracking, timing reflexes, and precision targeting.
2. Introduce progressive speed escalations to test focus under pressure.
3. Provide clean, accessible arcade entertainment on any browser.
