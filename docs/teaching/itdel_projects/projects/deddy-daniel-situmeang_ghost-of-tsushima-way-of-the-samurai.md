## 1. Deskripsi Proyek (Indonesian)
Ghost of Tsushima: Way of the Samurai adalah game aksi RPG berbasis web yang menghadirkan pertarungan pedang samurai sinematik dalam format 3D menggunakan teknologi Three.js WebGL. Pemain berperan sebagai Jin Sakai, sang pendekar dari klan Sakai yang berjuang membebaskan Pulau Tsushima dari serbuan penjajah Mongol. Game ini menyuguhkan sistem pertarungan taktis yang mendalam melalui mekanik tangkisan presisi (perfect parry), pengurasan postur lawan, serta pemilihan empat kuda-kuda katana—Stone, Water, Wind, dan Moon—yang disesuaikan secara khusus untuk merontokkan pertahanan tiap tipe musuh. Pemain juga dapat melancarkan duel refleks bertekanan tinggi lewat sistem Standoff, mengaktifkan mode amukan Ghost Stance, dan mengeksekusi jurus legendaris seperti Heavenly Strike menggunakan orbe Resolve. Unsur RPG diperkuat melalui menu kuil Golden Temple, tempat pemain membelanjakan poin teknik dan suplai untuk menempa ketajaman pedang, membuka efek unik set zirah, serta melengkapi jimat mistis (charms). Didukung oleh atmosfer sinematik lengkap dengan filter hitam-putih artistik Kurosawa Mode, bilah letterbox, dan efek visual luka yang dramatis, game ini menyajikan pengalaman bermain laga samurai feodal yang imersif dan menantang langsung dari peramban web.

## 2. Project Description (English Translation)
A cinematic 3D web action RPG set in feudal Japan. Players wield katana blades, execute precise parries and counter-attacks, and face invading enemy warlords across scenic historic landscapes.

## 3. Tujuan Proyek (Indonesian Objectives)
Tujuan utama dari proyek pengembangan game Ghost of Tsushima: Way of the Samurai adalah merancang pengalaman bermain aksi RPG bernuansa samurai feodal yang imersif dan sinematik langsung melalui peramban web modern tanpa membutuhkan pemasangan aplikasi tambahan. Memanfaatkan pustaka Three.js WebGL, proyek ini bertujuan membuktikan potensi teknologi web dalam mengeksekusi arena pertarungan tiga dimensi yang dinamis, didukung estetika film klasik lewat Kurosawa Mode, bilah letterbox, serta efek visual benturan pedang yang dramatis.   Dari segi interaksi pemain, proyek ini berfokus melatih ketangkasan refleks, fokus, serta pengambilan keputusan taktis melalui sistem pertarungan yang presisi. Mekanik ini mencakup penguasaan empat kuda-kuda katana untuk mengeksploitasi kelemahan musuh, eksekusi tangkisan sempurna (perfect parry), duel refleks berisiko tinggi (Standoff), hingga pemanfaatan orbe Resolve untuk jurus mistis maupun pemulihan diri.   Selain itu, proyek ini bertujuan mengintegrasikan kedalaman elemen perkembangan karakter ala RPG ke dalam ekosistem web. Melalui sistem Kuil Golden Temple, pemain dapat mengelola suplai dan poin teknik untuk menempa katana, memilih variasi zirah pelindung, serta memasang jimat suci (Sacred Charms). Secara keseluruhan, inisiatif ini dirancang guna menyajikan media hiburan aksi berkualitas tinggi yang memadukan keindahan narasi visual dengan gameplay laga yang menantang.

## 4. Project Objectives (English Translation)
1. Create an immersive cinematic swordplay experience using 3D web graphics.
2. Implement tight combat mechanics including stance shifts, parry timing, and combos.
3. Showcase procedural animation and atmospheric audio on the web platform.
