## 1. Deskripsi Proyek (Indonesian)
SmartSave Campus merupakan website edukasi literasi keuangan yang dirancang untuk membantu mahasiswa mempelajari cara mengelola keuangan secara sederhana, interaktif, dan menyenangkan. Website ini menggunakan konsep uang virtual sehingga pengguna dapat berlatih mengatur anggaran dan menabung tanpa melibatkan transaksi keuangan sungguhan.

SmartSave Campus memiliki beberapa fitur utama, yaitu Dashboard, Budget Planner, Savings Goals, Financial Quiz, Daily Missions, dan Reports. Pada Dashboard, pengguna dapat melihat saldo virtual, perkembangan target tabungan, learning points, serta misi yang telah diselesaikan. Fitur Budget Planner membantu pengguna mengatur alokasi uang berdasarkan kebutuhan, seperti makanan, transportasi, pendidikan, hiburan, dan tabungan. Melalui Savings Goals, pengguna dapat membuat target tabungan, misalnya untuk membeli laptop atau perlengkapan kuliah.

## 2. Project Description (English Translation)
A dedicated financial tracker tailored for university students, facilitating daily meal allowance budgeting, campus living cost tracking, and savings goal milestones.

---

## 3. Tujuan Proyek (Indonesian Objectives)
Tujuan pembuatan website SmartSave Campus adalah meningkatkan pemahaman dan kesadaran mahasiswa mengenai pentingnya pengelolaan keuangan sejak dini. Website ini dibuat untuk membantu mahasiswa belajar menyusun anggaran, membedakan kebutuhan dan keinginan, membangun kebiasaan menabung, serta memahami konsep dasar literasi keuangan melalui simulasi virtual. Selain itu, website ini bertujuan melatih kemampuan mengambil keputusan keuangan secara bijak, mengembangkan kedisiplinan dalam mengatur pengeluaran, dan menyediakan media pembelajaran yang interaktif serta mudah dipahami.

## 4. Project Objectives (English Translation)
1. Prevent end-of-month student financial crises through daily expense limits.
2. Provide clear visual breakdowns of food, academic supplies, and social expenditures.
3. Encourage saving habits through gamified target rewards.
