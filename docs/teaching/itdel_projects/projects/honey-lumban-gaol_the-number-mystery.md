## 1. Deskripsi Proyek (Indonesian)
Projek :
The Number Mystery adalah game berbasis terminal yang mengangkat tema misteri dan puzzle angka. Pemain berperan sebagai detektif yang harus memecahkan berbagai teka-teki angka untuk menemukan kode rahasia dan menyelesaikan sebuah misteri. Game ini dilengkapi dengan beberapa level, sistem petunjuk (hint), kesempatan (lives), sistem skor, dan beberapa kemungkinan ending berdasarkan hasil permainan pemain.

## 2. Project Description (English Translation)
A mathematical logic game where players deduce a secret number combination based on structural clues, parity hints, and arithmetic comparisons within limited guesses.

---

## 3. Tujuan Proyek (Indonesian Objectives)
Projek :
1. Membuat game puzzle angka yang menarik dan interaktif bagi pemain.
2. Melatih kemampuan berpikir logis dan memecahkan masalah melalui berbagai teka-teki angka.
3. Memberikan pengalaman bermain yang menantang melalui sistem level, petunjuk, kesempatan, dan skor.
4. Mengembangkan game sederhana yang dapat menjadi sarana hiburan sekaligus melatih ketelitian dan kemampuan berpikir pemain.

## 4. Project Objectives (English Translation)
1. Cultivate systematic deductive reasoning and process-of-elimination skills.
2. Enhance numerical intuition and pattern recognition.
3. Provide tiered challenges with score multipliers for rapid deductions.
