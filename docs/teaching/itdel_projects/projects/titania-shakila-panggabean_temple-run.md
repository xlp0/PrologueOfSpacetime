## 1. Deskripsi Proyek (Indonesian)
Temple Run adalah game aksi bergenre endless runner yang menghadirkan petualangan lari tanpa henti dengan mekanik gravitasi unik dan penuh tantangan. Dalam game ini, pemain diajak menelusuri lintasan dinamis sambil mengumpulkan koin sebanyak-banyaknya untuk meraih skor tertinggi. Pemain dituntut untuk bergerak lincah melalui aksi melompat, berguling, serta bergeser ke kanan dan ke kiri guna menghindari setiap rintangan yang menghalang. Game ini juga dilengkapi dengan fitur perisai pelindung (shield) yang memungkinkan pemain menerobos rintangan secara langsung tanpa perlu melakukan pergerakan menghindar selama durasi tertentu, menciptakan pengalaman bermain yang cepat, menegangkan, dan memicu adrenalin.

## 2. Project Description (English Translation)
A browser-based 3D endless runner capturing the iconic ancient temple escape adventure. Players swipe to turn sharp corners, jump over fiery gaps, and slide under obstacles while accumulating ancient relics.

---

## 3. Tujuan Proyek (Indonesian Objectives)
untuk menghadirkan sebuah game endless runner interaktif yang memadukan refleks ketangkasan pemain dengan mekanik elemen anti-gravitasi yang segar. Selain itu, proyek ini bertujuan untuk melatih kecepatan respons pemain melalui kontrol permainan yang intuitif, serta memberikan variasi strategi bermain dengan adanya fitur power-up seperti pelindung rintangan. Pada akhirnya, game ini dirancang untuk menciptakan daya tarik bermain ulang (replayability) yang tinggi, di mana pemain terdorong untuk terus melampaui rekor skor tertinggi mereka dan mengumpulkan koin terbanyak.

## 4. Project Objectives (English Translation)
1. Deliver responsive 3D swipe controls and fluid camera perspectives on web browsers.
2. Implement randomized obstacle generation and progressive velocity scaling.
3. Provide thrilling arcade gameplay accessible on mobile and desktop.
