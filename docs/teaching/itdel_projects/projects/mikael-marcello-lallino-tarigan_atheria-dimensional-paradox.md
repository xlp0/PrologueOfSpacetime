## 1. Deskripsi Proyek (Indonesian)
Bumi sudah hancur oleh invasi monster luar angkasa, tugas dari player adalah menjadi sebuah penyelamat bumi yang bisa mengontrol antara elemen api, air, dan petir. Dalam game aka nada monster yang harus dikalahkan oleh player untuk menyelamatkan dunai. Setiap kali monster dikalahkan, akan diberikan Soal kepada player, jika soal berhasil dikerjakan maka monster akan langsung kalah, namun jika soal salah atau tidak dikerjakan maka monster akan hidup Kembali. Dalam game seiring dengan susahnya level, maka soal akan semakin susah pula. Game menggunakan mekanisme _Turn-based Game_ yang akan semakin menantang player.

## 2. Project Description (English Translation)
A sci-fi action adventure game set on an Earth ravaged by extraterrestrial invaders. Players navigate dimensional rifts, scavenge energy cores, and deploy futuristic weaponry to reclaim human outposts.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Melatih kepandaian player dalam mengatus strategi
2. Melatih ketenangan siswa dalam mengerjakan sebuah soal
3. Melatih siswa dalam mengerjakan soal

## 4. Project Objectives (English Translation)
1. Create an atmospheric sci-fi narrative with dimensional travel mechanics.
2. Provide intense combat and puzzle-solving across diverse biomes.
3. Implement inventory crafting and character enhancement trees.
