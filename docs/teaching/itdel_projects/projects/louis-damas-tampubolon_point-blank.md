## 1. Deskripsi Proyek (Indonesian)
Game Point Blank
Point Blank adalah game online yang mengutamakan kemampuan menembak, strategi, kerja sama tim, dan kecepatan dalam mengambil keputusan. Dalam permainan ini, pemain bergabung dalam sebuah tim dan bertarung melawan tim lawan menggunakan berbagai jenis senjata, seperti pistol, senapan serbu, shotgun, sniper, dan senjata lainnya. Pemain dapat memilih karakter serta perlengkapan yang sesuai dengan gaya bermainnya.

Point Blank memiliki berbagai mode permainan, seperti Deathmatch, Bomb Mission, Destroy Mission, dan mode lainnya. Setiap mode memiliki aturan dan sasaran yang berbeda. Dalam pertandingan,  Game ini merupakan game tembak2 an yg terinspirasi dari point blank tujuan utama game ini adalah untuk menghabisi lawan dan naik level agar menjadi player yg terkuat untuk memenangkan sebuah match atau pertandingan tertentu.

## 2. Project Description (English Translation)
A tactical first-person combat simulation web game emphasizing weapon recoil control, map callouts, team positioning, and sharp shooting reflexes.

---

## 3. Tujuan Proyek (Indonesian Objectives)
Mengalahkan tim lawan dengan strategi dan kemampuan bermain yang baik.
Memenangkan pertandingan sesuai dengan aturan dari mode permainan yang dipilih.
Bekerja sama dengan tim untuk mencapai target permainan.
Meningkatkan kemampuan bermain, seperti akurasi, refleks, strategi, dan komunikasi.
Mendapatkan kemenangan dan meningkatkan peringkat dalam permainan.
Menyelesaikan misi tertentu, misalnya menghabisi seluruh lawan, menjaga area, atau memasang/menjinakkan bom, tergantung mode permainan.

## 4. Project Objectives (English Translation)
1. Simulate tactical team combat scenarios and fast-paced shooting mechanics.
2. Train quick situational decision-making and spatial awareness.
3. Explore competitive multiplayer web game architecture.
