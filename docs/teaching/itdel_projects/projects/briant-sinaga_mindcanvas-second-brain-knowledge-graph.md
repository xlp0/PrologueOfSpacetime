## 1. Deskripsi Proyek (Indonesian)
Aplikasi catatan pemikiran dan pengorganisasian ide pribadi bergaya Second Brain yang menggabungkan Markdown Editor modern dengan visualisasi jaringan pengetahuan interaktif (Knowledge Graph Canvas). Pengguna dapat menulis catatan secara terstruktur menggunakan format Markdown dengan pratinjau instan di sisi kanan, mengelompokkan topik dengan sistem tag, serta melihat bagaimana ide-ide saling terhubung dalam graf partikel node visual yang dinamis dan dapat digeser secara bebas.

## 2. Project Description (English Translation)
An interconnected note-taking and knowledge representation workspace that visualizes notes, entities, and research insights as an interactive node-link graph with bidirectional hyperlinking.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Melatih kemampuan siswa dalam menstrukturkan ide dan materi pelajaran secara rapi
2. Melatih daya analisis kognitif dalam menghubungkan konsep-konsep pengetahuan yang saling terkait
3. Meningkatkan retensi ingatan jangka panjang melalui visualisasi graf pengetahuan yang menarik

## 4. Project Objectives (English Translation)
1. Bridge fragmented notes into a unified, visual knowledge network.
2. Accelerate cognitive synthesis and exploratory learning.
3. Provide local-first, low-latency graph navigation.
