## 1. Deskripsi Proyek (Indonesian)
Subway Surfers 3D - Ultimate Web Edition adalah game web bergenre endless runner yang menghadirkan aksi pelarian seru di atas jalur rel kereta secara interaktif langsung melalui peramban. Dibangun menggunakan pustaka Three.js WebGL, game ini menyajikan visual grafis 3D yang dinamis lengkap dengan efek kecepatan (speed vignette) untuk menciptakan sensasi bermain yang imersif dan mulus. Pemain ditantang untuk mengendalikan karakter yang berlari tanpa henti guna meloloskan diri dari kejaran satpam, sembari bermanuver menghindari rintangan dan gerbong kereta yang melaju dengan melompat, berseluncur (slide), serta berpindah jalur rel. Sepanjang pelarian, pemain dapat mengumpulkan koin emas, menemukan kunci darurat untuk melanjutkan giliran bermain (revive), serta memanfaatkan perlengkapan khusus seperti hoverboard pelindung dan pengganda skor (multiplier boost). Koin dan kunci yang terkumpul dapat dibelanjakan di menu toko untuk membuka berbagai variasi karakter, papan seluncur baru, hingga meningkatkan durasi power-up. Game ini sangat fleksibel karena mendukung kontrol navigasi keyboard untuk pengguna komputer serta tombol virtual D-pad dan gestur usap (swipe) untuk perangkat seluler. Dengan kombinasi tantangan mencetak rekor skor tertinggi, jarak tempuh terjauh, dan audio yang energik, game ini menghadirkan pengalaman arkade klasik yang adiktif serta menghibur bagi segala kalangan.

## 2. Project Description (English Translation)
An endless runner web game where players navigate a young graffiti artist dodging subway cars, barriers, and pursuit along vibrant train tracks, collecting gold coins and high-score multipliers.

## 3. Tujuan Proyek (Indonesian Objectives)
Tujuan utama dari proyek pengembangan game Subway Surfers 3D - Ultimate Web Edition adalah menghadirkan adaptasi permainan endless runner 3D berbasis peramban (web-based) yang mudah diakses secara instan tanpa perlu instalasi aplikasi tambahan. Proyek ini memanfaatkan teknologi Three.js WebGL untuk membuktikan bahwa lingkungan grafis tiga dimensi yang dinamis, kaya efek visual kecepatan, dan performa tinggi dapat berjalan mulus langsung di atas platform web.   Dari sisi pengalaman pengguna, proyek ini bertujuan menguji dan melatih kecepatan refleks, konsentrasi, serta ketangkasan motorik pemain dalam bermanuver menghindari rintangan rel kereta di bawah tekanan tempo yang kian meningkat. Proyek ini juga mengimplementasikan mekanisme gamifikasi yang menarik melalui sistem pengumpulan koin emas, pencapaian skor tertinggi (high score), pemanfaatan item darurat seperti kunci revive, serta aktivasi perlengkapan pendukung seperti hoverboard pelindung.   Selain itu, tujuan teknis lainnya adalah menyediakan aksesibilitas lintas platform yang optimal. Hal ini diwujudkan lewat perancangan sistem kontrol yang adaptif, baik menggunakan keyboard bagi pengguna komputer desktop maupun tombol virtual D-pad dan gestur usap (swipe) bagi pengguna perangkat layar sentuh. Secara menyeluruh, proyek ini ditujukan untuk menciptakan media hiburan arkade modern yang kompetitif, adiktif, sekaligus membuktikan fleksibilitas pengembangan game interaktif pada ekosistem web modern.

## 4. Project Objectives (English Translation)
1. Deliver fast-paced arcade entertainment with responsive lane jumping and sliding.
2. Implement score multipliers, power-ups, and daily word letter collection challenges.
3. Test hand-eye coordination and reflex agility under steadily increasing game speed.
