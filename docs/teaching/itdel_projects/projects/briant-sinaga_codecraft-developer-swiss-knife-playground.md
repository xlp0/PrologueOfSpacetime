## 1. Deskripsi Proyek (Indonesian)
Platform utilitas pengembangan perangkat lunak terintegrasi yang dirancang untuk mempermudah proses coding dan pengujian data secara instan di browser. Aplikasi ini memuat empat modul utama: Regex Tester interaktif dengan penyorotan sintaks otomatis, JSON Formatter & Validator dengan inspeksi hierarki pohon, modul Enkripsi/Dekripsi (Base64, URL Encoding, dan Hash SHA-256 via Web Crypto API), serta generator CSS Glassmorphism dan Gradient visual dengan tombol salin kode siap pakai.

## 2. Project Description (English Translation)
An all-in-one in-browser utility playground for software developers, featuring formatters (JSON, SQL, Markdown), regex testers, hash generators, and isolated HTML/CSS/JS prototyping sandboxes.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Melatih logika dan pemahaman teknis siswa dalam pemrosesan data dan pola ekspresi reguler
2. Meningkatkan efisiensi serta akurasi pengembang dalam memformat dan memvalidasi struktur data
3. Memfasilitasi eksplorasi kreativitas desain antarmuka modern secara cepat dan interaktif

## 4. Project Objectives (English Translation)
1. Streamline daily engineering workflows into a single offline-capable web suite.
2. Eliminate reliance on ad-heavy external web tools.
3. Enable rapid experimentation and code snippet validation.
