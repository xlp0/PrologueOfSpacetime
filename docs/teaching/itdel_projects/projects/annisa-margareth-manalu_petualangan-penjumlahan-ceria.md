## 1. Deskripsi Proyek (Indonesian)
Projek : Petualangan Penjumlahan Ceria merupakan game edukasi yang dirancang agar belajar matematika terasa menyenangkan seperti bermain, bukan ujian sekolah. Pemain harus menjawab soal penjumlahan acak berformat pilihan ganda (4 opsi) dalam batasan waktu tertentu.
Game ini menyediakan tiga tingkat kesulitan progresif: Mudah (penjumlahan 1-5), Sedang (1-10), dan Sulit (1-20). Dilengkapi sistem 3 nyawa (\hearts), efek suara interaktif, serta pesan penyemangat seperti "Mantap!" dan "Kamu luar biasa!", game ini menyajikan pengalaman bermain yang kompetitif namun santai. Tampilannya cerah, menarik, dan responsif sehingga nyaman dimainkan di HP maupun komputer, lengkap dengan navigasi tombol Mulai Game, Pilih Level, Pause, Main Lagi, dan Keluar.

## 2. Project Description (English Translation)
An interactive educational math game designed to make elementary arithmetic engaging and stress-free. Players solve random multiple-choice addition problems across three progressive difficulty tiers (Easy: 1-5, Medium: 1-10, Hard: 1-20). Features 3 lives, celebratory sound effects, and encouraging feedback.
