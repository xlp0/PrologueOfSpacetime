## 1. Deskripsi Proyek (Indonesian)
Silangit Flight Board adalah aplikasi web Flight Information Display System (FIDS) yang dirancang untuk menyediakan informasi keberangkatan dan kedatangan pesawat di Bandara Internasional Raja Sisingamangaraja XII / Silangit (DTB) secara real-time. Web ini dilengkapi fitur pencarian kilat, filter status penerbangan, informasi cuaca kawasan Danau Toba, serta desain antarmuka aviation dark mode yang responsif dan ultra-cepat.

## 2. Project Description (English Translation)
A sleek, real-time Flight Information Display System (FIDS) web application tailored for Silangit International Airport (DTB), displaying scheduled departures, arrivals, gate assignments, and status updates.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Aksesibilitas Informasi: Memudahkan penumpang memantau jadwal, gate, dan status penerbangan secara cepat.
2. Efisiensi Antarmuka: Menyediakan papan informasi penerbangan modern tanpa dependensi library berat.
3. Pengalaman Pengguna: Menghadirkan sistem pemantauan penerbangan yang responsif di komputer dan smartphone.

## 4. Project Objectives (English Translation)
1. Streamline passenger flight tracking with clean visual schedules and status indicators.
2. Provide airport operators with a lightweight, high-performance web display board.
3. Ensure multi-device responsiveness across passenger smartphones and airport terminal monitors.
