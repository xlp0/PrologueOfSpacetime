## 1. Deskripsi Proyek (Indonesian)
Math Adventure adalah game petualangan matematika berbasis permainan peran yang memadukan pemecahan logika angka dengan mekanisme pertarungan taktis berbasis giliran di Negeri Numeria. Pemain berperan sebagai pahlawan yang menjelajahi tingkatan dunia fantasi dengan menyelesaikan tantangan operasi hitung dan teka-teki logika angka untuk menaklukkan monster. Aplikasi ini dilengkapi dengan sistem perkembangan level karakter, akumulasi koin emas, inventori perlengkapan senjata dan perlindungan, petunjuk visual bertahap, serta mode petualangan terstruktur. Game ini dirancang secara khusus untuk meningkatkan ketajaman berpikir komputasional, daya analisis matematis, dan kecepatan pemecahan masalah mahasiswa melalui simulasi petualangan interaktif.

## 2. Project Description (English Translation)
A role-playing math adventure where players explore the fantasy Realm of Numeria, battling mystical beasts by solving mental arithmetic and logic puzzles. Features hero leveling, weapon/armor gear, step-by-step hints, and quest campaigns.
