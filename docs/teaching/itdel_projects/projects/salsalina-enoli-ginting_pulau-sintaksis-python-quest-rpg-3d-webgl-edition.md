## 1. Deskripsi Proyek (Indonesian)
Pulau Sintaksis* adalah game edukasi petualangan RPG *open-world* yang dirancang untuk mengajarkan dasar-dasar pemrograman Python secara interaktif. Berlatar di sebuah pulau surealis, pemain berperan sebagai penjelajah yang terdampar dan harus memperbaiki pesawat yang rusak di tengah alun-alun pulau. Untuk mengumpulkan suku cadang pesawat, pemain harus menjelajahi berbagai wilayah pulau, menyelesaikan 10 *quest* materi Python (mulai dari sintaks dasar `print`/`input`, percabangan, fungsi, hingga *error handling*), serta menaklukkan tantangan mini-game aksi arkade (*shooter*, *platformer*, dan *dash*).

## 2. Project Description (English Translation)
An open-world educational RPG set on a surreal island where a stranded explorer must repair their crashed airplane by solving 10 progressive Python programming quests (syntax, branching, loops, functions, error handling) and conquering arcade mini-games.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Menyediakan media edukasi pemrograman yang interaktif dan menyenangkan melalui konsep gamifikasi dunia terbuka (*open-world*).
  2. Meningkatkan pemahaman algoritma dan logika koding pengguna lewat penyelesaian masalah nyata, instruksi *pseudocode*, dan validator kode langsung.
  3. Mengasah ketangkasan sekaligus menguji fokus pengguna dengan mengintegrasikan pembelajaran koding bersama mini-game aksi arkade yang menantang.

---

## 4. Project Objectives (English Translation)
1. Teach Python fundamentals through an engaging open-world 3D narrative.
2. Reinforce algorithmic thinking with in-game code validators and pseudocode puzzles.
3. Balance intellectual learning with reflex-testing arcade mini-game challenges.
