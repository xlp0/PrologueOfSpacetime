## 1. Deskripsi Proyek (Indonesian)
# VALO HOOPS: 2K TACTICAL

**VALO HOOPS: 2K TACTICAL** adalah gim bola basket 3D berbasis web yang mengombinasikan mekanisme tembakan taktis ala *NBA 2K* dengan kemampuan khusus (*hero skills*) khas karakter *Valorant*.

## Cara Kerja
Proyek ini dibangun menggunakan **Three.js** untuk rendering grafis 3D interaktif di dalam *browser*. Pemain mengontrol agen pilihan dalam pertandingan basket dengan mekanisme tembakan berbasis indikator *timing* (*green release* untuk akurasi presisi). Selain mengandalkan simulasi fisika bola basket, pemain dapat mengaktifkan *skill* taktis unik setiap agen untuk memanipulasi pergerakan dan strategi permainan secara *real-time*.

## Fungsi
Proyek ini berfungsi sebagai sarana permainan *arcade basketball* yang responsif dan dapat dimainkan langsung melalui peramban web tanpa instalasi perangkat lunak tambahan. Gim ini menyediakan berbagai pilihan mode permainan interaktif, termasuk **1v1 Duel**, **2v2 Team Battle**, serta **Practice Gym** untuk melatih akurasi tembakan dan penguasaan kemampuan agen.

## 2. Project Description (English Translation)
A hybrid arcade sports game blending tactical shooter ability kits with fast-paced street basketball mechanics, allowing players to execute skill shots, teleport passes, and kinetic slam dunks.

---

## 3. Tujuan Proyek (Indonesian Objectives)
* **Inovasi Permainan**: Menyajikan kombinasi unik antara genre olahraga dan *tactical hero shooter* yang menyegarkan.
* **Melatih Ketangkasan**: Mengasah fokus, koordinasi mata-tangan, dan kecermatan respons pemain melalui penguasaan *timing release* tembakan.
* **Aksesibilitas Grafis Web**: Memamerkan potensi grafis 3D berkualitas tinggi berbasis teknologi web yang ringan dan mudah diakses siapa saja.

## 4. Project Objectives (English Translation)
1. Innovate by fusing tactical hero abilities with basketball physics.
2. Implement trajectory projection, rim collision physics, and shot timing gauges.
3. Offer highly competitive, skill-based arcade gameplay.
