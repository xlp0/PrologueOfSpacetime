## 1. Deskripsi Proyek (Indonesian)
FlameVision AI* adalah aplikasi pendeteksi api *real-time* berbasis *Computer Vision* menggunakan Python dan OpenCV. Sistem mengenali kobaran api dari kamera laptop, smartphone (via WebRTC), maupun video rekaman melalui segmentasi ruang warna ganda (*HSV & YCrCb*) dan operasi morfologi citra.

Aplikasi menampilkan *bounding box* berlabel *`FIRE DETECTED`*, banner status bahaya, dan alarm sirene audio. Proyek ini hadir dalam dua antarmuka: aplikasi desktop interaktif dan Web Dashboard modern yang dapat diakses langsung melalui browser berbagai perangkat.

## 2. Project Description (English Translation)
An automated early-warning fire detection application utilizing Python, OpenCV, and deep learning computer vision to recognize flame signatures, smoke patterns, and heat anomalies from live camera video feeds.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. *Peringatan Dini Kebakaran:* Mendeteksi kobaran api secara instan sejak detik pertama untuk mencegah kebakaran fatal.
2. *Pengawasan Visual Jarak Jauh:* Menyediakan sistem pemantauan tanpa sentuh (*non-contact*) untuk area luas.
3. *Akurasi Tinggi & Rendah *False Alarm*:* Memfilter warna api secara ketat guna membedakannya dari lampu atau objek jingga biasa.
4. *Aksesibilitas Multi-Perangkat:* Memungkinkan pemantauan langsung dari HP atau laptop melalui browser tanpa instalasi tambahan.

## 4. Project Objectives (English Translation)
1. Provide instantaneous fire recognition to mitigate industrial and residential fire risks.
2. Minimize false alarms through multi-spectral color and motion contour analysis.
3. Trigger automated alert broadcasts and emergency notifications upon fire detection.
