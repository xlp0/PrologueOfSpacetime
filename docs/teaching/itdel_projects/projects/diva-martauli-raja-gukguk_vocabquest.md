## 1. Deskripsi Proyek (Indonesian)
VocabQuest adalah aplikasi permainan edukasi berbasis web interaktif yang dirancang untuk mengasah penguasaan kosakata dan ungkapan bahasa Inggris melalui lima variasi mode permainan menarik, yaitu pilihan ganda arti kata, susun huruf acak, deteksi sinonim-antonim, tebak idiom kiasan, serta mode bertahan waktu intensif. Sistem kerja game ini beroperasi secara mandiri pada peramban web tanpa memerlukan server tambahan, dengan memanfaatkan basis data kosakata bertingkat yang terintegrasi secara langsung dengan teknologi Web Speech API untuk fitur pelafalan suara asli penutur dan Web Audio API untuk menghasilkan efek suara sintetis yang reaktif. Permainan ini juga menerapkan sistem gamifikasi lengkap berupa perolehan poin pengalaman (XP), peningkatan peringkat profil pemain, pengganda kombo jawaban benar, serta penyediaan fasilitas bantuan strategis seperti pembuka contoh kalimat konteks dan eliminasi dua opsi jawaban yang keliru. Untuk menggunakannya, pemain cukup membuka berkas file aplikasi di peramban, menentukan tingkat kesulitan yang diinginkan, kemudian memilih mode permainan di menu utama. Saat berada di arena kuis, pemain dapat mendengarkan audio pengucapan kata, membaca instruksi soal, lalu memilih opsi atau menyusun huruf yang tepat sebelum batas waktu habis. Apabila menemui soal yang sulit, pemain dapat memanfaatkan bantuan yang tersedia, dan setelah ronde permainan selesai, seluruh kata dapat dipelajari kembali melalui menu kamus pintar Vocab Vault.

## 2. Project Description (English Translation)
A gamified vocabulary learning quest where players encounter contextual word puzzles, phonetic pronunciations, and synonym challenges across varied quest scenarios.

3. Keep learners engaged through level progressions and achievement unlocks.
