## 1. Deskripsi Proyek (Indonesian)
Brain Runner 3D: Cyber Quiz Parkour adalah game edukasi aksi 3D berbasis peramban web yang memadukan ketegangan lari rintangan berkecepatan tinggi dengan kuis interaktif yang mengasah otak. Menggunakan teknologi Three.js WebGL, pemain berlari menelusuri lintasan futuristik sambil bermanuver melompat, meluncur (slide), dan berpindah jalur untuk menerobos gerbang jawaban yang benar. Game ini menyediakan beragam topik pertanyaan, mulai dari matematika, sains, bahasa Inggris, hingga logika, lengkap dengan empat tingkat kesulitan dan mode permainan seperti Endless Cyber Run serta Stage Adventure.   Pengalaman bermain terasa kian dinamis berkat fitur mekanik Slow-Mo untuk memperlambat waktu saat menganalisis soal genting, sistem kombo beruntun (streak), pengganda skor (multiplier), serta sudut pandang kamera yang dapat diganti antara orang ketiga dan orang pertama. Pemain juga dapat mempersonalisasi warna visor karakter favoritnya serta memanfaatkan fitur Custom Quiz Builder untuk merancang, menyimpan, maupun mengimpor paket soal sendiri secara fleksibel. Dilengkapi kontrol responsif untuk desktop maupun layar sentuh seluler, Brain Runner 3D menghadirkan sarana belajar yang adiktif, kompetitif, dan memacu adrenalin langsung dari peramban web.

## 2. Project Description (English Translation)
An adrenaline-fueled educational hybrid combining futuristic parkour running with rapid-fire trivia quizzes. Runners sprint across neon rooftops, jumping through gate portals corresponding to correct answers.

## 3. Tujuan Proyek (Indonesian Objectives)
Tujuan utama dari proyek pengembangan game Brain Runner 3D: Cyber Quiz Parkour adalah merancang media pembelajaran interaktif berbasis web yang memadukan aksi ketangkasan fisik digital dengan evaluasi pengetahuan secara menyenangkan dan dinamis. Memanfaatkan pustaka Three.js WebGL, proyek ini bertujuan membuktikan bahwa format kuis edukatif dapat dikemas ke dalam lingkungan visual 3D futuristik yang berkecepatan tinggi tanpa memerlukan instalasi aplikasi tambahan.   Secara pedagogis dan motorik, proyek ini dirancang untuk melatih fokus, kecepatan berpikir, dan refleks pemain dalam mengambil keputusan kritis di bawah tekanan waktu dan kecepatan laju lintasan. Hal ini diwujudkan melalui mekanik navigasi jalur gerbang jawaban, manuver parkour lompat dan berseluncur (slide), serta fitur pengatur tempo waktu Slow-Mo. Keberagaman topik soal—seperti sains, bahasa Inggris, logika, hingga generator matematika tanpa batas—juga ditujukan untuk memperluas wawasan intelektual pengguna lintas disiplin ilmu.   Selain itu, proyek ini berfokus pada fleksibilitas pembelajaran mandiri melalui penyediaan fitur Custom Quiz Builder, yang memungkinkan pengajar maupun pengguna membuat serta mengimpor paket soal sendiri secara mandiri. Secara keseluruhan, inisiatif ini bertujuan menciptakan sarana gamifikasi edukasi yang adiktif, kompetitif, dan mudah diakses lintas perangkat.

## 4. Project Objectives (English Translation)
1. Merge physical reflexes with intellectual trivia retrieval under high-speed constraints.
2. Gamify academic quiz modules into dynamic obstacle-avoidance gameplay.
3. Foster cognitive agility by forcing simultaneous motor control and logical reasoning.
