## 1. Deskripsi Proyek (Indonesian)
Game endless runner berbasis web yang dibuat menggunakan HTML5 Canvas dan vanilla JavaScript tanpa framework eksternal. Pemain mengendalikan karakter mahasiswa yang terlambat masuk kelas dan harus berlari menghindari berbagai rintangan seperti tumpukan tugas, buku berserakan, kursi dan meja, teman yang mengajak nongkrong, kasur yang menggoda untuk tidur, hingga dosen yang berjalan di koridor. Sepanjang permainan, pemain dapat mengumpulkan item bonus berupa kopi untuk speed boost, buku dan laptop untuk tambahan skor, jam untuk tambahan waktu, serta energy drink untuk kecepatan ekstra. Game dilengkapi dengan sistem 3 nyawa, timer countdown 90 detik, peningkatan kecepatan bertahap, efek suara prosedural, animasi karakter, efek partikel, serta tampilan UI modern dengan desain glassmorphism. Game mendukung kontrol keyboard maupun sentuh untuk perangkat mobile.

## 2. Project Description (English Translation)
A humorous 2D endless runner chronicling the frantic campus dash of a university student racing across campus obstacles (stairs, roaming pets, security gates) to reach the classroom before the lecturer closes the door.

---

## 3. Tujuan Proyek (Indonesian Objectives)
Mengembangkan game web interaktif yang fully playable sebagai implementasi konsep pemrograman web meliputi HTML5 Canvas rendering, JavaScript OOP, game loop, collision detection, dan state management. Project ini bertujuan mendemonstrasikan kemampuan membangun aplikasi web kompleks dan responsif dengan tema kehidupan mahasiswa yang relatable, menghibur, serta memiliki pengalaman pengguna yang menarik dan engaging.

## 4. Project Objectives (English Translation)
1. Capture relatable student life experiences in an engaging arcade format.
2. Implement responsive hurdle jumps, slide mechanics, and power-up pick-ups.
3. Entertain while promoting punctual campus attendance awareness.
