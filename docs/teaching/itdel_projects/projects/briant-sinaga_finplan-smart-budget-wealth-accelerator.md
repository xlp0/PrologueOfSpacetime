## 1. Deskripsi Proyek (Indonesian)
Aplikasi manajemen keuangan personal dan perencanaan kekayaan cerdas berbasis web. Pengguna dapat mencatat pemasukan dan pengeluaran harian secara real-time yang langsung divisualisasikan dalam bentuk diagram donat interaktif berbasis Canvas HTML5. Aplikasi ini menerapkan Aturan 50/30/20 untuk membagi proporsi keuangan secara ideal antara Kebutuhan Pokok, Keinginan Pribadi, dan Tabungan Masa Depan, serta dilengkapi simulator investasi bunga majemuk (compound interest) dinamis untuk memproyeksikan akumulasi aset jangka panjang.

## 2. Project Description (English Translation)
A lightweight personal finance and budgeting web platform featuring automated expense categorization, visual financial allocation meters, and proactive savings milestone projections.

---

## 3. Tujuan Proyek (Indonesian Objectives)
1. Melatih kesadaran finansial siswa dalam mengelola pemasukan dan pengeluaran uang
2. Melatih kepandaian pengguna dalam mengatur alokasi anggaran belanja secara strategis
3. Mengembangkan pemikiran visioner tentang investasi dan pertumbuhan aset masa depan

## 4. Project Objectives (English Translation)
1. Empower students and young professionals to take control of personal cash flows.
2. Prevent overspending through intuitive visual budget alerts.
3. Gamify savings milestones with clear projection trajectories.
