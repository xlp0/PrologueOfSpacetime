# The AI Coding Handbook

> A handbook for anyone who wants to understand what AI coding tools are, what they can do, and how to work with them responsibly. Written so a 14-year-old can follow along.

---

## How to Read This

This handbook is split into short chapters. Each one explains **one idea** and what it is **for**. You do not need to read them all at once. Read in order if you are new, or jump to any chapter that interests you.

If a word is new to you, check [Chapter 12: The Words You'll Hear](12_words_youll_hear.md) — it is a glossary of all the terms used in this handbook.

## Who This Is For

You. Whether you are a student, a junior developer, a curious adult, or a teenager who has heard about AI coding and wants to understand it — this handbook is written for you.

You do not need to know how to code to read it. You do not need to know what an LLM is. You just need to be curious.
