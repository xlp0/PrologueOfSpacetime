# VCard (Verification / Validation Card)

> The **pre/post boundary type** — the sovereign I/O gatekeeper. The Id-type (Identity Type) of the MVP Cards triad; the mathematical proof object that gates every state transition.

## Definition

**VCard** is the **Vector** component: the structured insight, the verifiable claim. It operates as the paired mathematical path or proof object ($V_{pre} \xrightarrow{\text{PCard}} V_{post}$) that gates every state transition — validating preconditions *before* execution and verifying postconditions *after*, sealing each transition with a cryptographic execution trace (BHK interpretation). VCard is the **sovereign boundary**: the gatekeeper separating the exposed world from the protected world.

| Dimension | VCard |
|:---|:---|
| Math | Id-type (Identity Type) — the path/proof |
| Role | Verification boundary; I/O gatekeeper |
| Pattern | Pre/post-condition pairs; BHK interpretation |
| Property | Cryptographic execution trace |

## In the Representation Engine

VCard is **Tier 3 — Compose** of the D&D word-game loop: $5! = 120$ orderings — permutation generates the namespace of possible worlds. The card that composes arrangements (and whose combinations explode combinatorially) is the VCard. The fourth tier (Prove → {P}C{Q}) is the [[Representability]] collapse where VCard's verification becomes adjudication.
