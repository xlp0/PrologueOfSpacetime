# Document Relationship Map

> A graph-theoretic and conceptual map of how every wiki page relates to every other. Generated by parsing all `[[wikilinks]]` across 258 markdown files (1,447 links), then enriching with conceptual analysis of the orphan islands. Filed as [[AGENTS]] §6.2 "good answers compound."

## 1. Graph topology

The wiki is **one giant connected component of 150 files** (the dense core) plus **108 isolated files** (42% of the wiki) with zero inbound or outbound wikilinks.

| Region | Files | Status |
|:---|---:|:---|
| Connected core | 150 | Interlinked via wikilinks |
| Orphan islands | 108 | No links in or out |
| **Total** | **258** | |

The core is healthy and dense. The orphan islands — detailed in §4 — are the primary relationship debt: large swaths of real content (teaching, edge-computing, hardware, changelogs) are invisible to the graph view and unreachable by link-following.

Within the connected 150-file core, five tightly-knit clusters exchange the most links:

1. **Create the MCard / VCard / PCard stub pages** (resolves 58 dangling links). Each is a card type in the Representation Engine — define in one place and let the 58 inbound links resolve.
2. **Reconnect the 108 orphan islands** by adding 2–4 wikilinks per orphan file per the tables in §4. Highest-leverage: the 27 chapter topic files (§4.1) and the 20 shopper-analytics files (§4.3), since these connect the curriculum and the deployed system to the theory.

5. **Mark `PIPELINE_8080` as `status: stale`** (superseded by port 5000).
6. **Convert path-based markdown links to wikilinks** in chapter topic files — several use `(../03_.../sonic_synchronization.md)` style links that Obsidian's graph doesn't follow.

## 7. How to read this map

- **For navigation**: start at [[index]], then follow the cluster that matches your interest (§3). The narrative and improvement clusters are the theory; chapters and shopper-analytics are the practice.
- **For maintenance**: the §5 dangling list and §4 orphan tables are the lint backlog. Work top-down by mention count.
- **The graph data** lives at `src/extract_link_graph.py` (re-runnable) and `/tmp/wiki_graph.json` (full edge list). Re-run after major ingests to refresh this map.
