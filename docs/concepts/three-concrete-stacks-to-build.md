# Three Concrete Stacks to Build

## Insight
Three concrete operator stacks Ilham could actually build with GLM2 + OpenCode + Obsidian + (optional) SQLite. The blunt take: the most interesting 3 hit Ilham's real bottlenecks — too much scattered information, too many decisions, too much rethinking the same terrain.

**1. Personal investment war room.** Agent watches Indonesia macro / BI / MSCI / FTSE / Moody's / commodity prices / filings / news / insider moves on Ilham's watchlist. Gives daily brief, "what changed in my thesis?" alerts, alerts only when something actually matters. Instead of rereading the same noise every day, it acts like a junior analyst.

**2. Career sniper.** Not just "apply to jobs." Track masters deadlines, scholarships, WHV windows; monitor jobs in SG/Aus/remote AI roles; rank opportunities by money + visa + long-term upside; draft tailored applications; remind when to follow up. One dashboard for escaping drift.

**3. AI coding operator on real repos.** This is where GitNexus actually matters. If Ilham is building (1) or (2) as software (dashboard, scraper, thesis tracker, application manager), then the coding stack becomes worth it: GitNexus for codebase intelligence, harness for agent loop, repo memory, test/debug loops. Stops being a toy and becomes Ilham's in-house engineer.

Other candidates that came up but ranked lower: ghost chief of staff (decision memos across goals/finances/constraints/prior thinking — overlaps with investment war room), training/boxing/physique operator (fatigue/sleep/weight tracking with deload advice), personal knowledge machine (RAG over books/articles/notes — already covered by Obsidian+OpenCode), content/writing operator (LinkedIn posts, cold outreach, scholarship essays, cover letters using Ilham's stored voice).

**The harness gives value only when you have a recurring process to hand over.** Without that, Claude/OpenAI + OpenCode is already 80–90% of the value. "Most of the 'full stack agent' stuff is just packaging around: memory, tools, scheduled workflows, repo indexing. Useful, yes. Revolutionary? Only if you have a recurring process to hand over."

## Context
Came up 2026-06-25 (Harness Explanation). Ilham had asked: "I cant imagine something I would do" with a full agent stack.
