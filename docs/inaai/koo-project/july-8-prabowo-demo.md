# July 8 Prabowo Demo

## Insight
On July 8, 2026, President Prabowo Subianto was scheduled to come try the InaAI assistant. Press would attend; Prabowo would ask the AI questions to see that it is "just as good as foreign AI, just that this was developed by anak bangsa." This is the front-stage political demo, distinct from the back-stage capability-building pipeline (kids/Lego/PKC).

The realistic objective is **not** "this is literally better than ChatGPT/Claude across the board" — that would be reckless without serious evidence. The realistic objective is: an Indonesian-hosted AI assistant that is good enough on selected tasks to show sovereign capability. Runs on local infra (Toba), maybe uses an open-source base model, maybe tuned/wrapped/tool-augmented locally, can answer government/Indonesia-relevant questions, looks competent in a live demo.

Two layers happening at once: (1) **capability-building theater/pipeline** = kids, Lego, math game, process extraction, PKC, "we can manufacture builders"; (2) **flagship national AI demo** = InaAI / Prabowo / July 8 / data center / local model — the political-commercial showpiece. **PKC is the workshop. InaAI is the showroom.** PKC = how you train, structure, and build. InaAI = the thing you wheel out in front of Prabowo and say "lihat, this is ours."

Two weeks before a major demo, the team needs evaluation, red teaming, QA, prompt testing, multilingual testing, documentation, benchmark creation, failure-mode identification more than another ML researcher. The model is probably mostly frozen by then; fixes happen via prompt engineering, system prompt adjustments, retrieval (RAG) improvements, demo preparation, and risk identification — not retraining. Ilham's Invisible background (RLHF, calibration, multilingual eval, quality analytics) is unusually useful for a "demo in 2 weeks" situation.

## Context
Came up 2026-06-20 (inaAI Overview and Fit) when Ilham was deciding whether to fly from Jakarta to Bali on short notice for the InaAI prep.
