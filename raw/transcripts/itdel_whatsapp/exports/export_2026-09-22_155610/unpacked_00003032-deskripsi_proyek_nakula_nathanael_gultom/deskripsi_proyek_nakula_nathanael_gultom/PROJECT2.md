# JUDUL : LAST HOPE: Road to Zombie Bastion
# NAMA : NAKULA NATHANAEL GULTOM
# DESKRIPSI PROJEK :

**LAST HOPE: Road to Zombie Bastion** adalah game petualangan web bertema *zombie apocalypse* yang menggabungkan penceritaan bergaya komik interaktif dengan lima *minigame* aksi yang menantang. Game ini dibangun secara murni menggunakan HTML5, CSS3, dan JavaScript Vanilla tanpa ketergantungan pustaka eksternal.

### 🌟 Fitur Utama

- **Story Mode Interaktif:** Cerita naratif apokaliptik yang disajikan melalui visual komik dinamis, membawa pemain menelusuri alur cerita emosional menuju benteng pertahanan terakhir (*Bastion*).
- **5 Minigame Aksi Bervariasi:**
  1. **Sniping Outpost:** Aksi penembak jitu jarak jauh menggunakan *scope* presisi.
  2. **Deteksi Infeksi:** Pemindaian tubuh penyintas untuk mendeteksi gejala infeksi virus.
  3. **Perbaikan Sirkuit:** Puzzle menghubungkan alur kabel listrik di bawah tekanan waktu.
  4. **Highway Driving:** Simulasi mengemudi melintasi jalan tol terhalang rintangan dan gerombolan zombie.
  5. **Sabotase Inti Bastion:** Peretasan sistem reaktor untuk menonaktifkan inti reaktor berbahaya.
- **Arcade Mode:** Ruang khusus bagi pemain untuk memainkan dan melatih setiap *minigame* secara bebas.
- **Audio & Visual Imersif:** Efek suara sintetis berbasis Web Audio API dan antarmuka bernuansa *tactical survival OS* yang responsif.

Game ini menyajikan pengalaman bermain yang responsif, penuh ketegangan, dan imersif bagi para pecinta genre *survival action*.
