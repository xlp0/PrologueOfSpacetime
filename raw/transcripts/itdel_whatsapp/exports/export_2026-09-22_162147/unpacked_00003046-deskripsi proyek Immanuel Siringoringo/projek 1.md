# 🍳 Culinary Bistro: Realistic Gourmet Kitchen Simulator 3D

## 📌 Deskripsi Proyek
**Culinary Bistro 3D** adalah game simulasi memasak *first-person* 3D berbasis web yang menghadirkan pengalaman realistis seorang koki di dapur restoran gourmet. Game ini memadukan interaksi fisika objek (*grab & drop*), pemotongan bahan, pengaturan suhu kompor induksi, serta simulasi reaksi kematangan termal (*Maillard reaction*) untuk melayani pesanan pelanggan dalam batas waktu tertentu.

---

## 🎯 Tujuan Proyek

1. **Menghadirkan Simulasi Memasak Realistis:** Memberikan pengalaman interaktif mengolah bahan mentah menjadi hidangan gourmet melalui mekanik suhu wajan, tingkat kematangan (*doneness*), dan perpaduan bumbu yang akurat.
2. **Melatih Manajemen Waktu & Fokus (*Time Management*):** Menguji ketangkasan dan strategi pemain dalam mengelola alur pesanan tiket di bawah tekanan waktu (*Endless Shift Mode*).
3. **Mengembangkan Game 3D Berbasis Web yang Ringan:** Memanfaatkan Three.js (WebGL) dan Web Audio API untuk menghasilkan grafis 3D interaktif serta audio prosedural yang mulus langsung di browser tanpa instalasi tambahan.
4. **Memberikan Sistem Penilaian Objektif & Edukatif:** Menyajikan evaluasi hidangan berdasarkan 4 pilar utama: ketepatan komponen resep, akurasi kematangan, higienitas dapur, dan kecepatan penyajian.

---

## 🛠️ Teknologi yang Digunakan
* **Graphics & Rendering:** Three.js (WebGL)
* **Core Logic & Physics:** Vanilla JavaScript (ES6+) & Custom AABB Physics
* **Audio:** Procedural Web Audio API Synthesis
* **UI & Styling:** HTML5 & Modern Glassmorphism CSS3

---

## 🎮 Kontrol Permainan
* **W, A, S, D:** Bergerak
* **Mouse:** Mengarahkan pandangan (*First-Person*)
* **Klik Kiri:** Ambil objek / Potong bahan / Aksi utama
* **Klik Kanan:** Taruh objek presisi / Lepas pegangan
* **E:** Masuk / Keluar Mode Fokus Kompor (*Dedicated Cooking Station*)
* **Spasi:** Mengatur level panas api kompor (di Mode Kompor)
* **ESC / P:** Jeda permainan (*Pause*)
